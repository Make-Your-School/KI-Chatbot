# Google AI Studio (Gemini) Modell-Fallback-Liste für den Mentor*innen KI Chat.
#
# Diese Datei ist git-versioniert. Änderungen entweder lokal committen und
# auf dem Server `git pull`, oder direkt auf dem Server editieren (dann aber
# zurückcommitten, sonst gehen sie beim nächsten Pull verloren).
#
# Der Server liest die Datei live (mtime-cached) — kein Restart nötig.
#
# Format:
#   - Eine Modell-ID pro Zeile, in Reihenfolge der Bevorzugung
#   - Anders als OpenRouter macht Google kein Server-Side-Routing — der
#     Server iteriert selbst durch die Liste und probiert das nächste, wenn
#     eins 429 oder 5xx zurückgibt
#   - `#` kommentiert den Rest der Zeile aus, Leerzeilen werden ignoriert
#   - Optional hinter der Modell-ID, durch ein Leerzeichen getrennt, das
#     Tageslimit des Anbieters fuer dieses Modell:
#
#         gemini-3.5-flash-lite 1000
#
#     Das ist NUR eine Anzeige fuer /stats ("Tagesbudget -> Pro KI-Modell").
#     Der Server bremst nicht danach — das Limit gehoert dem Anbieter, und
#     selbst zu bremsen wuerde ein Modell aussperren, das dort noch Luft hat.
#     Ohne Eintrag steht in der Statistik nur die Zahl, kein Balken. Lieber
#     kein Limit als ein geratenes: ein erfundener Balken sieht aus wie Wissen.
#
# Wo finde ich Modell-IDs?
#   https://ai.google.dev/gemini-api/docs/models  → Spalte "Model code"
#   Free-Tier-Verfügbarkeit: https://ai.google.dev/gemini-api/docs/pricing
#   Deine echten Limits:     https://aistudio.google.com/rate-limit
#
# ---------------------------------------------------------------------------
# Stand 23.09.2026 — Liste aktualisiert.
#
# Warum: die vorherige Liste war veraltet.
#   - gemini-3.1-flash-lite-preview  → es gibt jetzt eine STABILE Version
#                                      ohne "-preview". Preview-Modelle werden
#                                      irgendwann abgeschaltet.
#   - gemini-2.5-flash / -flash-lite → Google schränkt die 2.5er-Generation auf
#                                      Bestandsnutzer ein. Läuft bei dir evtl.
#                                      noch, ist aber kein Fundament mehr.
#   - gemma-3-*                      → durch Gemma 4 abgelöst.
#
# Reihenfolge wie gehabt:
#   - zuerst Flash-Lite: höhere Anfragen-pro-Minute-Quote, ideal für viele
#     kurze Schüler*innen-Fragen gleichzeitig
#   - dann die stärkeren Flash-Modelle
#   - dann offene Gemma-Modelle als Rückfall
#
# Alle folgenden Modelle haben laut Google einen Free Tier.
# Im Chat steht unter jeder Antwort, welches Modell tatsächlich geliefert hat —
# damit kannst du direkt prüfen, ob die Reihenfolge so aufgeht wie gedacht.
# ---------------------------------------------------------------------------
