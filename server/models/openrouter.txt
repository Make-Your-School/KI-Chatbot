# OpenRouter Modell-Fallback-Liste für den Mentor*innen KI Chat.
#
# Diese Datei ist git-versioniert. Änderungen also entweder lokal committen
# und auf dem Server `git pull`, oder direkt auf dem Server editieren (dann
# aber daran denken, sie zurückzucommitten, sonst gehen die Änderungen beim
# nächsten Pull verloren).
#
# Der Server liest die Datei live (mtime-cached) — kein Restart nötig.
#
# Format:
#   - Eine Modell-ID pro Zeile, in Reihenfolge der Bevorzugung
#   - OpenRouter probiert sie der Reihe nach: erstes Modell, das antwortet,
#     wird genommen. Bei 429/Provider-down → nächstes
#   - `#` kommentiert den Rest der Zeile aus, Leerzeilen werden ignoriert
#   - Optional hinter der Modell-ID, durch ein Leerzeichen getrennt, das
#     Tageslimit des Anbieters fuer dieses Modell:
#
#         meta-llama/llama-3.3-70b-instruct:free 1000
#
#     Das ist NUR eine Anzeige fuer /stats ("Tagesbudget -> Pro KI-Modell").
#     Der Server bremst nicht danach — das Limit gehoert dem Anbieter, und
#     selbst zu bremsen wuerde ein Modell aussperren, das dort noch Luft hat.
#     Ohne Eintrag steht in der Statistik nur die Zahl, kein Balken. Lieber
#     kein Limit als ein geratenes: ein erfundener Balken sieht aus wie Wissen.
#
# Wo finde ich Modell-IDs?
#   https://openrouter.ai/models?max_price=0  → Modell anklicken → ID kopieren
#
# Reihenfolge für diesen Chat:
#   - zuerst gute allgemeine Text-/Instruktionsmodelle
#   - dann kleinere oder weniger verlässliche Fallbacks
#   - Coder-, Thinking-, Vision- und sehr kleine Modelle absichtlich ganz unten
